# sh

Shell scripts.

## finx.sh

The [Finx](https://github.com/Fincote/Finx) installer. It is a byte-for-byte
copy of
[`finx-install/install.sh`](https://github.com/Fincote/Finx/blob/main/finx-install/install.sh),
renamed.

```sh
curl -fsSL https://raw.githubusercontent.com/Fincote/sh/main/finx.sh | sudo bash
```

Do not edit `finx.sh` here. It is generated by `finx-install/build-bundle.sh`
in the Finx repository from `finx-install/install.sh.in` and
`finx-install/lib/*.sh`; change it there.

`.github/workflows/finx.yml` copies the upstream file over this one daily and
on demand, and rejects any pull request that edits it. The file carries no
local difference at all, so a mismatch here means this copy is simply out of
date.

Installation, mirrors, seeds, and offline use are documented in
[Fincote/Finx](https://github.com/Fincote/Finx#readme).
